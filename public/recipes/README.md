# Recipe image assets

Recipe photos use the exact naming contract `public/recipes/<recipe-id>.jpg`, where
`<recipe-id>` matches the recipe's exported `id` in `src/data.js` (for example,
`public/recipes/nasi-lemak.jpg`). The application refers to these files as
`/recipes/<recipe-id>.jpg`.

Approved photo direction: warm, natural-light food photography with a 4:3 crop,
the finished Malaysian dish clearly visible in a simple home-kitchen setting,
realistic portions, and restrained props. Keep the plate or bowl centered with
enough negative space for UI overlays. Avoid logos, text, watermarks, people,
and exaggerated or inauthentic garnish.
